# Транспорт М5

Приложение для плана работ и отчётов водителей.

- Основной адрес: https://basiha02.github.io/TransportM5/ (GitHub Pages — стабильно открывается из России)
- Второй адрес: https://transport-m5.vercel.app (Vercel — из России иногда бывает белый экран)
- База данных: Supabase, проект Basiha02's Project (бесплатный тариф)
- Ежедневная выгрузка в Google Таблицу «Транспорт М5 — отчёт по заявкам»: файл `google-sheets-script.js`
- Запасной канал связи с базой через Google: функция `doPost` в том же файле, опубликована как веб-приложение

## Связь с базой (важно для России)

Российские провайдеры с 2025 года режут Cloudflare, через который работает Supabase: пропускают ~16 КБ,
дальше соединение «замерзает». Поэтому приложение ходит в базу тремя путями:

1. **напрямую** в Supabase;
2. **через Google** — веб-приложение Apps Script (`doPost` в `google-sheets-script.js`) передаёт запрос в базу
   со стороны Google; адрес канала — константа `RELAY_URL` в `src/App.js`;
3. **напрямую через новое соединение** (адрес базы с точкой на конце).

Если путь не ответил за 3 секунды, запрос параллельно уходит следующим путём. Зависший путь на время уходит в конец.

Если связи нет совсем, запись не теряется: она лежит в памяти устройства (очередь) и уходит сама, когда связь
появится, даже после перезапуска. Последний загруженный план тоже хранится на устройстве и виден без связи.

Приложение само проверяет новую версию каждые 10 минут и перезагружается, когда не открыта ни одна форма.
Номер версии (дата и время выкладки) виден внизу экрана и на экране входа.

Если меняли скрипт таблицы: в Apps Script → «Начать развертывание» → «Управление развертываниями» →
карандаш → «Версия: новая» → «Развернуть». Адрес веб-приложения при этом не меняется.

## Что лежит в папке

| Файл / папка | Что это |
|---|---|
| `src/App.js` | Весь код приложения |
| `src/index.js` | Запуск приложения (не трогать) |
| `public/` | Логотип, значки, страница сайта |
| `package.json` | Список компонентов для сборки |
| `google-sheets-script.js` | Программа для Google Таблицы (вставляется в Расширения → Apps Script) |
| `Запустить М5.bat` | Запуск приложения на этом компьютере (http://localhost:3000) |
| `Обновить с GitHub.bat` | Скачать последнюю версию кода |
| `node_modules/` | Компоненты, ставятся автоматически, можно не смотреть |

## Как это работает

Изменения в коде попадают на сайт после загрузки в GitHub (github.com/Basiha02/TransportM5) —
Vercel пересобирает сайт сам за 1–2 минуты. Локальная копия на компьютере работает с той же базой,
что и сайт.

## Выкладка новой версии

1. Изменения в `main` — Vercel пересобирает сайт сам.
2. Для GitHub Pages собрать с подпапкой и залить в ветку `gh-pages`:
   `PUBLIC_URL=/TransportM5 npm run build`, затем содержимое `build/` (+ пустой файл `.nojekyll`
   и копия `index.html` под именем `404.html`) — в ветку `gh-pages`.
