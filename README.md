# Транспорт М5

Приложение для плана работ и отчётов водителей.

- Сайт (для всех сотрудников): https://transport-m5.vercel.app
- База данных: Supabase, проект Basiha02's Project (бесплатный тариф)
- Ежедневная выгрузка в Google Таблицу «Транспорт М5 — отчёт по заявкам»: файл `google-sheets-script.js`

## Что лежит в папке

| Файл / папка | Что это |
|---|---|
| `src/App.js` | Весь код приложения |
| `src/index.js` | Запуск приложения (не трогать) |
| `public/` | Логотип, значки, страница сайта |
| `package.json` | Список компонентов для сборки |
| `google-sheets-script.js` | Программа для Google Таблицы (вставляется в Расширения → Apps Script) |
| `Запустить М5.bat` | Запуск приложения на этом компьютере (http://localhost:3000) |
| `Обновить с GitHub.bat` | Скачать последнюю версию кода |
| `node_modules/` | Компоненты, ставятся автоматически, можно не смотреть |

## Как это работает

Изменения в коде попадают на сайт после загрузки в GitHub (github.com/Basiha02/TransportM5) —
Vercel пересобирает сайт сам за 1–2 минуты. Локальная копия на компьютере работает с той же базой,
что и сайт.
